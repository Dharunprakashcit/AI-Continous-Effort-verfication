# Student Failure Early Warning (19MAM56 Advanced ML, CAT II)

This project predicts whether a student will **pass** (final grade G3 ≥ 10) **before any grades exist**. It uses the
[UCI Student Performance](https://doi.org/10.24432/C5TG7T) dataset (1,044 students, Math + Portuguese) and benchmarks
the result against Cortez & Silva (2008).

| Rubric item | Where |
|---|---|
| Data engineering, validation, encoding | `src/data.py` |
| PCA and t-SNE | `src/analysis.py` → `figures/03_pca_variance.png`, `04_embeddings.png`. PCA+XGBoost ablation in `src/train.py` |
| 12 visualisations (EDA, correlation, ROC/PR, confusion matrix, calibration, Optuna, SHAP summary/bar/waterfall) | `figures/` |
| XGBoost, LightGBM, CatBoost, RF, MLP, LogReg | `src/models.py` |
| Optuna (TPE Bayesian) tuning with 5-fold stratified CV | `src/train.py` |
| MLflow experiment tracking (one run per model, nested run per trial) | `mlruns/` |
| Benchmark vs paper (same 10-fold protocol, setups A/B/C) | `src/benchmark.py`, `benchmark_baseline.json`, `artifacts/benchmark_report.json` |
| Error analysis (segments, threshold trade-off, SHAP of worst error) | `artifacts/error_analysis.json` |
| Flask API with input validation | `api.py` (`/predict`, `/schema`, `/health`) |
| Gradio UI with per-student SHAP drivers | `app.py` |
| Docker image (Hugging Face Spaces ready) | `Dockerfile`, `start.sh` |
| Configuration | `config.yaml`, `requirements.txt` |
| IEEE report | `report/AML_Report.pdf` (generated by `src/report.py`) |
| Tests | `tests/test_api.py` |

## Reproduce

```bash
pip install -r requirements.txt
python -m src.train        # Optuna + MLflow, ~17 min on 12 threads
python -m src.benchmark    # paper comparison
python -m src.analysis     # figures, SHAP, error analysis
python -m src.report       # report/AML_Report.html
python -m pytest tests
```

View the experiments with `mlflow ui --backend-store-uri mlruns`. This needs the full `mlflow` package; `mlflow-skinny` only logs runs.

PDF: open `report/AML_Report.html` in Edge or Chrome, then Print → Save as PDF. You can also run it headless:
`msedge --headless --no-pdf-header-footer --print-to-pdf=report/AML_Report.pdf report/AML_Report.html`

## Run locally

```bash
python api.py      # http://localhost:8080
python app.py      # http://localhost:7860
curl -X POST localhost:8080/predict -H "Content-Type: application/json" -d "{\"failures\": 2, \"absences\": 20, \"higher\": \"no\"}"
```

## Docker

```bash
docker build -t student-failure-aml .
docker run -p 7860:7860 -p 8080:8080 student-failure-aml
```

## Deploy to Hugging Face Spaces

1. Create a Space on huggingface.co (SDK: **Docker**).
2. Push this folder to it. The YAML header at the top of this README configures the Space.
   ```bash
   git init && git add . && git commit -m "deploy"
   git remote add space https://huggingface.co/spaces/<user>/<space-name>
   git push space main
   ```
   The `artifacts/champion.pkl` file must be committed. It is small (~170 KB).
3. Put the Space URL and the GitHub URL into the report, then rebuild it:
   `HF_SPACE_URL=... GITHUB_URL=... python -m src.report`.

> Note: `benchmark_baseline.json` holds the paper's reported accuracies. Check them against Table 3 of Cortez & Silva (2008) before you submit.
